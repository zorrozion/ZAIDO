# VoiceFollow (语音跟稿 / 智能讲稿跟随器)

> **让讲稿跟着你的声音移动。**  
> 面向主日讲道、神学授课、公众演讲的高鲁棒性本地优先（Local-First）智能提词器。

---

## 🌟 项目亮点

- 🛡️ **本地优先与绝对隐私 (Local-First & Private)**：
  - 100% 运行于浏览器本地内存，无用户账号、无云端数据库、不存储或上传讲稿文本。
- 🎙️ **高鲁棒性语音跟随 (Robust Speech Tracking)**：
  - 基于 Web Speech API (`webkitSpeechRecognition`)，针对 **30–60 分钟、5,000–10,000 字中文超长逐字稿** 设计。
  - **宁可少动，绝不乱跳**：脱稿插话时原地驻留，回到讲稿时快速重捕；跳段需连续二次确认方可触发；严惩反向大步倒退。
- 🎯 **黄金阅读区平滑滚动 (35%–45% Viewport Centering)**：
  - 当前正讲句子始终平滑居中在视口 **38% 黄金视线高**，给讲者留出充裕的视线前瞻空间。
  - **防抢占冷却机制**：讲者用手指或鼠标手动滑动查看时，自动跟随贴心挂起 4 秒，绝不与讲者抢夺视野。
- 📱 **完美适配 iPad 与平板**：
  - 支持局域网 HTTPS 安全访问与麦克风授权。
  - 支持添加到 iPad 主屏幕实现「全屏无边框专业提词器」。
- 🧪 **内置长篇测试套件与推流模拟器**：
  - 内置 1,000 字、5,000 字、10,000 字真实讲道文本。
  - 内置免开麦语音模拟器（支持 1x/2x/4x 倍速、一键注入脱稿插话、跳段验证）。

## 🏗️ 算法架构

```text
[麦克风收音 / 模拟器推流] 
        ↓
[环形语音滑动缓冲区 (120 字)]
        ↓
[文本正规化 & 语气词降权 (弟兄姊妹/然后/那么/就是)]
        ↓
[局部滑动窗口搜寻 (current - 5 ~ current + 25)]
        ↓
[多维打分: 时效加权 Dice (0.50) + 关键词 (0.25) + 空间连续性 (0.25)]
        ↓
[多帧连续确认与防跳跃状态机]
   ├─ 高置信顺延 ──> 立即推进
   ├─ 远距离跳段 ──> 需连续 2 次确认通过后平滑跳转
   ├─ 脱稿/低置信 ──> 原位驻留 (HOLD)
   └─ 持续失锁 ────> 严格阈值全局重定位
        ↓
[35%–45% 视口死区居中平滑滚动]
```

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动本地开发服务 (支持 HTTPS / iPad)

```bash
npm run dev
```

终端将输出本地及局域网访问地址：
- 本机访问：`https://localhost:5173/`
- 局域网 / iPad 访问：`https://<你的局域网IP>:5173/`

### 3. 运行核心算法自动化测试

项目包含了完整的长文本遍历、脱稿驻留、跳跃确认与单向锁定单元测试：

```bash
npm test
```

### 4. 生产环境构建

```bash
npm run build
```

## 📱 iPad 使用指南

1. **同局域网连接**：确保 iPad 与电脑连接至同一个 Wi-Fi。
2. **在 Safari 中打开**：访问 `https://<你的电脑局域网IP>:5173`。
3. **信任证书**：首次访问自签名证书时，点击「显示详细信息」➔「访问此网站」。
4. **授予权限**：点击「开始跟稿」并在弹窗中允许麦克风权限。
5. **添加到主屏幕（推荐）**：在 Safari 中点击「分享」按钮 ➔「添加到主屏幕」，即可享受原生 App 般的无边框全屏提词体验。
